# Analysis-of-Scientific-Articles-from-Moroccan-Universities

This project aims to analyze scientific articles from universities in Morocco, leveraging data scraped from Scopus using Scrapy. The key focus of the analysis is to assess the scientific output from Moroccan universities and identify trends in publication, journal types, and author affiliations.

#### Data Collection:
The project starts with scraping Scopus data, focusing on articles published by Moroccan universities. Data is collected on article metadata such as author names, affiliations, DOI, journal types, and publication years.

#### Data Structure:
The data model is designed around key entities:
Affiliation: University, city, and country data.
Author: Information on the authors, their names, and ORCID identifiers.
Metadata: Includes article IDs, document types, keywords, and more.
Journal: Information on the journal, categories, and performance metrics (e.g., H-index, citations per document).

#### Data Analysis:
The analysis is visualized using Power BI, focusing on:
The number of articles published by each university and affiliation.          
Article trends by year and type of journal (e.g., conference papers, journal articles).   
Geographical distribution of articles across various cities and universities.    
Scientific impact and performance of journals based on SJR Best Quartile rankings.    
Detailed author analysis to track publication counts and their association with various affiliations.       
Key Insights:     
The distribution of articles by year reveals publication trends over time.     
The SJR Best Quartile data helps assess the quality of journals in which the articles were published.       
Geospatial analysis shows which cities and universities in Morocco are the most active in scientific research.       
The number of articles by journal type highlights the predominant formats for Moroccan university research publications.
